# Venzy

**Seu tempo organizado. Seus clientes na agenda.**

Protótipo web responsivo de agenda e gestão de clientes com tema azul e branco.

## Funcionalidades
- Painel com resumo de agendamentos e clientes.
- Criar agendamentos com data, hora, serviço, status e valor.
- Pesquisa e filtro por data na agenda.
- Cadastro e pesquisa de clientes.
- Perfil do negócio.
- Dados guardados localmente no navegador via `localStorage`.

## Como testar
Abra [`index.html`](./index.html) no navegador ou publique o repositório com GitHub Pages.

> Este é um protótipo front-end. Os dados ficam no dispositivo/navegador e ainda não são sincronizados entre aparelhos nem protegidos por login. Não use dados reais sensíveis nesta versão.
